# 本地模型（本機 llama.cpp）

機密照片走這條：照片只在 `127.0.0.1` 之間流動，不出這台電腦，也不需要金鑰。
選項名稱原本寫 Hugging Face，實際接的是 **llama.cpp 的 `llama-server`（GGUF ＋ OpenAI 相容端點）**，已改名。

## 先把伺服器開起來

1. 執行 `D:\Qwen3.8-27B\start.bat`（那個視窗要一直開著），預設 `http://127.0.0.1:8080`。
2. 模型要**帶 `--mmproj`** 才看得懂照片；`start.bat` 找得到 `models\mmproj-F16.gguf` 就會自動帶上，
   找不到會印 `TEXT-ONLY mode` —— 這種狀態下辨識一定失敗。
3. 顯卡記憶體不夠（out of memory）就把 `--n-gpu-layers` 調小。

## 在工具裡使用

頂列「🤖 AI 辨識」→ 辨識方式選「本地模型」→ 確認網址 → 按「測試連線」
（向 `/v1/models` 要型號清單、再試打一句）→ 選型號 → 開始辨識。
網址與型號記在瀏覽器 `autofit:v1:local`，下次直接帶回來。

## 程式位置

- `web/js/recognizer/local/server.js`：HTTP 呼叫（`/v1/models`、`/v1/chat/completions`），逾時 10 分鐘（本機大模型一張要好幾分鐘）。
- `web/js/recognizer/local/settings.js`：網址與型號的保存。
- `web/js/recognizer/local.js`：辨識器本體；照片縮到 1500px（與 LLM API 同尺寸，實測結果才比得起來）。
- 提示詞組裝與回覆解析與 LLM API 共用 `api/prompt.js`，輸出格式見該檔的 `OUTPUT_SPEC`。
- 對話框在 `web/js/ui/recognize.js`（`#local-panel`）。

## 已知限制

- 這是**單一伺服器單一模型**：llama-server 一次只載一個模型，清單通常只有一筆。
- 辨識速度取決於顯卡；27B 量化版一張照片可能要數十秒到數分鐘，進度條會一張一張跑。
- 準確度尚未實測。LLM API 那邊的實測結論（小型號讀不動手寫白板）見 `docs/辨識實測-尺寸11F.md`。
