# 部署到 GitHub Pages

網站是純前端（`web/`，無建置步驟），推到 GitHub 後由 `.github/workflows/pages.yml` 自動發布：
**https://ianyuchuang.github.io/zidongtian-Auto-Fit/**

## 第一次要做的設定（只做一次）

1. repo 改成公開：Settings → General → 最下方 Danger Zone → Change visibility → Public。
   （免費帳號的私有 repo 不能用 Pages；已確認 git 內沒有金鑰與工地照片。）
2. Settings → Pages → Build and deployment → Source 選 **GitHub Actions**。
3. 之後每次 `2_推至GitHub.bat` 推到 main，Actions 分頁會跑 `pages`，約一分鐘網站更新。

## 與 localhost（3 號 bat）的差異

- 「載入範例」按鈕不會出現（那是 `tools/dev_server.py` 的 `/samples/` 提供的）。
- 讀寫資料夾一樣要 Chrome / Edge。
- LLM API 直打不受影響。
- 本機 llama.cpp 辨識：https 網頁打 `http://127.0.0.1:8080`，新版 Chrome 有「本機網路存取」權限規則，
  可能跳授權或被擋；被擋就改用 3 號 bat 開 localhost 版跑本機辨識（照片本來就不上傳）。
