# 介面規格 — 定案 B+E 混合工作台（2026-09-02）

視覺稿：`docs/ui-BE-mockup.png`；可編輯畫布在 Claude 專案「自檢表照片製作工具」的 Artifact「自懂填 Auto-Fit 介面板型」（第 2 頁為落選的 A–E）。
需求背景見 `docs/需求摘要.md`。

## 頁面
1. **入口頁**：選資料夾（點選/拖放）、板型（點選/拖放 docx，預設＝V1.0 版面）、提示詞（白板欄位位置，留空用預設）、檢查日期（民國，預設今天）、辨識方式（本地模型 / LLM API）→「開始讀取」。
2. **工作台**（單頁三欄）
   - **頂列**：資料夾、板型、日期三個 pill；「批次修改設計值」；「產生 Word 檔」。
   - **左欄 200px・資料夾樹**：根資料夾 + 子資料夾 + 張數；「新增資料夾」；底部辨識進度／已確認／待校對。
   - **中欄・可篩選表格**：篩選 chip（全部／檔名解析／AI 待校對／低信心）+ 搜尋內容說明。表格欄：拖曳把手｜縮圖｜內容說明｜設計｜實際｜信心｜狀態，依資料夾分組（群組列）。三欄可直接在儲存格編輯，Tab／Enter 移動。
   - **右欄 380px・檢視器**：檔名 + 狀態；大圖（左下疊日期）；白板裁切圖；三欄（與表格同步）；「跳過」「確認，下一張（Enter）」；上一張／下一張。

## 互動規則
- 表格列拖把手 → 改順序（＝Word 輸出順序）。
- 表格列拖到左樹某資料夾 → 實際搬移檔案到該資料夾。
- 點列 → 右欄顯示該張；右欄「確認」→ 狀態變「已確認」並跳下一張待校對。
- 狀態：`檔名解析`（檔名符合「內容說明-設計-實際」格式，灰）、`AI 辨識・待校對`（黃，欄位虛線底色）、`AI 低信心・請確認`（紅）、`已確認`（綠）。
- 信心欄：AI 結果顯示百分比；檔名解析顯示「—」。低信心門檻待定（草稿 <70%）。

## 資料流
掃描資料夾 → 每張照片：檔名可解析 → 直接預填；否則 → 兩階段辨識（低解析定位白板 → 原圖裁切 → 辨識三欄 + 信心）→ 表格。
產生 Word 沿用 `self_check_core.py` 的排版（每頁 3 列 × 2 張、標楷體、日期戳）。
