# 自懂填 Auto-Fit — 自主檢查表超強照片工具

把一個資料夾的工地照片，自動排成「施工自主檢查照片」Word 檔；照片上的白板手寫（內容說明／設計值／實際值）由 AI 讀出來預填，人只做校對。

**線上使用：https://ianyuchuang.github.io/zidongtian-Auto-Fit/** （Chrome / Edge，照片不會上傳）

## 解決什麼問題

公共工程做自主檢查，每天要把幾十張照片貼進 Word、調大小、疊日期、再一張張看白板抄「內容說明、設計、實際」等資訊，還得把照片分類。
這個工具把這些重複動作全部自動化：

| 原本 | 現在 |
|---|---|
| 一張張貼、排版、調大小、疊日期 | 選資料夾，一鍵產出 |
| 看白板抄三欄 | AI 辨識預填，只需校對 |
| 回辦公室依樓層／設計值分類 | 照資料夾分組，介面裡拖曳就能改順序、搬資料夾 |
| 每個工程案版型不同 | 拖入該案的 docx 樣本，照它的版面產出 |

## 功能

- **讀資料夾**：直接開電腦上的照片資料夾（含子資料夾），已照 `內容說明-設計-實際.jpg` 命名的照片會自動解析檔名預填。
- **AI 辨識白板**：三種方式擇一
  - `本地模型`：接本機的 llama.cpp（`llama-server`），照片只在 127.0.0.1 之間流動，適合機密案場。(但你的電腦也要夠強，實測跑qwen3.8-27b-q4_k_m沒問題。)
  - `LLM API`：填自己的金鑰直打 Claude／Gemini／GPT（Grok 待接），型號從該家清單現選；金鑰可存瀏覽器或用完即忘。
  - `不辨識`：手動填。
  - 辨識期間停在工作台顯示進度，每筆結果記錄用了哪個引擎。
- **工作台**：左資料夾樹、中間可篩選的表格（每張照片一列，三欄直接改）、右側大圖與白板裁切檢視器。支援多選、拖曳排序、拖曳搬資料夾、刪除（搬進該資料夾的 `_回收桶`，可還原）。
- **檢查日期**：每個資料夾一個日期（民國），用在檔名、頁首、照片日期戳、版型的「拍照日期」欄。
- **版型**：拖入其他工程案的 docx，整份解析出頁面、抬頭、格線、說明欄位與日期戳，在版型頁所見即所得地調（抬頭與說明格可直接打字、欄位是可拖的膠囊、可換填入順序與對齊），存進版型庫重複使用。不選版型就用預設版面（A4 每頁 3 列 × 2 張、標楷體）。
- **輸出**：每個資料夾一份 `民國日期 資料夾名.docx`，每頁都有抬頭；可勾選同時產出一份合併的 PDF（用電腦上的標楷體，沒有就退回全字庫正楷體）。
- 校對結果暫存在瀏覽器，重開同一個資料夾會帶回來；不會在照片資料夾裡留任何東西（除了輸出檔與 `_回收桶`）。

## 操作方式

1. 開網址，用 Chrome 或 Edge。
2. **入口頁**：點選或拖入照片資料夾；需要的話按「讀取版型」拖入該案的 docx 樣本、調整後按「完成」。
3. **工作台**：頂列「🤖 AI 辨識」選方式（本地模型／LLM API）→ 測試連線 → 選型號 → 開始。辨識完逐張校對三欄，需要就拖曳調整順序或搬資料夾，在資料夾列填檢查日期。
4. 頂列「產生 Word」→ 授權寫入 → docx（與 PDF）存回各資料夾。

## 運作邏輯

- **純前端，無伺服器**。整個工具是靜態網頁，讀資料夾靠瀏覽器的 File System Access API，docx 在瀏覽器裡用 `docx` 函式庫產生，PDF 用 `pdf-lib` 照同一份版面自己畫。照片與產出都留在你的電腦；唯一會把照片送出去的是你自己選的 LLM API，而且是直接送到該公司、不經過任何中間伺服器。
- **辨識流程**：照片縮到 1500px → 連同提示詞送給模型 → 模型回傳「內容說明／設計／實際」JSON → 填進表格標示為待校對。本地模型與 LLM API 共用同一套提示詞與解析，結果才比得起來。
- **版型解析**：docx 是 ZIP 裡的 XML。工具用瀏覽器內建的解壓讀 `document.xml`，從 `sectPr` 取頁面、主表格前的段落或頁首取抬頭、有圖片的列辨認照片格、`vMerge` 換算合併儲存格、「欄位名：值」認出說明欄位，整理成一份 LayoutSpec；讀不懂的列會列出來，不會安靜地套預設值。
- **產出**：LayoutSpec 描述「一張照片佔的格子」，產出時把它橫向重複、縱向排到照片用完；同一份 spec 同時餵給 Word 與 PDF 兩個產生器。

## 環境需求

- Chrome 或 Edge（讀寫資料夾與電腦字型需要）。
- 本地模型：一台能跑 llama.cpp 視覺模型的電腦（帶 `--mmproj`）。
- LLM API：各家自己的金鑰（要儲值；小型／快速型號讀不動手寫白板，實測見 `docs/辨識實測-尺寸11F.md`）。
