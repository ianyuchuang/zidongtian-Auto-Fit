隱私權政策

自懂填 Auto-Fit（以下稱「本工具」）・最後更新：2026-09-07

本工具是一個純前端的靜態網頁，沒有自己的伺服器、沒有帳號、沒有資料庫。你選的照片、校對的內容與產出的 Word／PDF，全部在你自己電腦的瀏覽器裡處理，不會傳給本工具的作者。以下逐項說明資料會留在哪裡、什麼情況下會離開你的電腦。

1. 照片與產出的檔案

本工具透過瀏覽器的 File System Access API 直接讀取你選擇的資料夾，並把產出的 docx／PDF 寫回同一個資料夾。這些資料不會上傳到任何伺服器；唯一的例外是第 3 節所述、由你主動選擇的 LLM API 辨識。

2. 存在你瀏覽器裡的資料

為了讓你下次打開時不必重來，本工具會把以下資料存在你這台電腦的瀏覽器（localStorage／sessionStorage／IndexedDB）。這些資料只有這台電腦、這個瀏覽器讀得到，本工具的作者無法取得。

資料用途存在哪裡
校對結果（內容說明／設計／實際、AI 辨識的信心值與所用引擎）重開同一個資料夾時帶回來localStorage，依根資料夾名分開
版型庫、各資料夾上次用的版型不必每次重讀 docxlocalStorage
上次開啟的資料夾的存取權杖下次一鍵重開（仍需你按一次授權）IndexedDB
本地模型伺服器的網址與型號下次直接帶回localStorage
LLM API 金鑰辨識時呼叫該公司 API預設記住：貼上即存 localStorage。勾「不要記住金鑰」則只放 sessionStorage，關閉分頁即清除（瀏覽器「重新開啟已關閉的分頁」時可能被還原）

清除方式：在瀏覽器設定中清除本網站的網站資料，或在辨識設定裡把金鑰清空。

3. 什麼情況下資料會離開你的電腦

只有在你於「AI 辨識」中選擇 LLM API、填入自己的金鑰並按下開始時，本工具才會把照片（縮至長邊 1500px）與提示詞直接從你的瀏覽器送到你所選公司的 API 端點（Anthropic／Google／OpenAI），不經過本工具作者的任何伺服器。送出後的資料如何處理，依該公司的隱私權政策與 API 使用條款：

  • Anthropic（Claude）：隱私權政策
  • Google（Gemini）：隱私權政策
  • OpenAI（GPT）：隱私權政策

機密照片請改用「本地模型」：照片只在 127.0.0.1 之間流動，不會離開這台電腦；或選「不辨識」手動填寫。

4. 電腦字型

勾選「同時產出 PDF」時，本工具會請求讀取你電腦上的「標楷體」字型檔以嵌入 PDF（瀏覽器會跳出授權）。字型只用來產生 PDF，不會上傳。拒絕授權時改用內附的全字庫正楷體。

5. 主機與存取紀錄

本網站由 GitHub Pages 代管。如同所有網站，GitHub 可能會記錄你的 IP 位址等連線資訊，詳見 GitHub 隱私權聲明。本工具作者不會收到這些紀錄。

6. Cookie、分析與廣告

本工具不使用 cookie、不裝任何流量分析工具、沒有廣告。除了第 3 節你主動選擇的 LLM API 之外，本工具不會與任何第三方交換資料。若日後有變動，本頁會先更新。

7. 政策變更與聯絡

本頁內容若有變動，會更新頂端的「最後更新」日期。對隱私有任何疑問，請到 GitHub Issues 提出。
